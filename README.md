# Bubble & Brew 🫧

A push-your-luck bag-builder at an alchemist's cauldron. Draw ingredient chips
out of your bag one at a time — every chip stirs the potion higher and the
points climb much faster near the top — but too much fizzroot and the lid comes
off and the round is gone. Stop in time, spend the coins at the apothecary, and
the bag you gamble with next round is the one you just built.

**Play it:** https://rvenning.github.io/bubble-brew/

## The game

- **One decision, over and over.** Draw again, or bottle it. Everything else in
  the game exists to make that decision interesting.
- **20 recipes across 5 chapters**, each five rounds long, each with its own
  starting bag, its own apothecary shelf and its own star targets.
- **11 ingredient families.** Calmwort settles the fizz, glimmercap pays coins
  the moment it lands, owl's eye shows you what's coming, emberbark pays a bonus
  only if you stop, echobell doubles the next chip (fizz included), thornvine
  catches a fizzroot outright, quicksilver draws again whether you wanted it to
  or not.
- **Coins survive a blow-up; points don't.** So exploding in round one is a
  shopping trip and exploding in round five is a disaster — the same mechanic
  changes meaning as the brew goes on.
- **Buying is diluting.** Every chip you buy goes into the bag for the rest of
  the brew, making everything else rarer. Ten chips you love beat twenty you
  half-want.
- **The Larder** — permanent perks bought with essence: a heavier lid, a head
  start up the pot, spectacles that show you the first chip, salvage that
  rescues some points from a wreck.
- **The Bottomless Cauldron** — endless mode, one life, and a fizz limit that
  falls forever while the bag sours. That's the family leaderboard score.
- **The Daily Cauldron** — the same bag, shuffle and shop for everyone, seeded
  by the date.

Aimed at Rosalie and up, and genuinely good for adults — the depth is in
compounding decisions rather than reflexes, and there is no clock anywhere.

## Built on gamekit

Profiles with PINs, family sync across devices, the sound engine, screens and
modals, and PWA install all come from the shared
[gamekit](https://github.com/rvenning/gamekit) library, vendored into `lib/`.

Re-vendor after a gamekit change:

```bash
node "../gamekit/tools/sync-to-game.js" "../bubble-brew"
```

Never edit `lib/` directly — the next sync overwrites it.

## Layout

```
js/rng.js           deterministic seeds, derived from coordinates not a stream
js/ingredients.js   every chip, the closed effect vocabulary, the track's payoff
js/brews.js         the 20 recipes and 5 chapters
js/perks.js         the Larder
js/round.js         ONE round: bag, draw, effects, blow-up, bottle it
js/game.js          a whole brew: five rounds, the apothecary, stars
js/storage.js       progress shape and the cross-device merge
js/render.js        the cauldron on canvas
js/main.js          screens and all the DOM
tests/              node --test: data linters, the merge, and the balance bots
```

`round.js` and `game.js` touch no DOM, no canvas and no `Math.random` — the same
objects are driven by `main.js` and by the headless bots in `tests/`.

## PWA

`manifest.json`, `sw.js` (network-first, bump `CACHE` whenever a shell file
changes) and `icons/` generated by `node tools/make-icons.js`.

## Local development

```bash
npx http-server . -p 8119 -c-1
```

Then open http://localhost:8119/index.html. `?debug=1` adds the debug panel —
note that it deliberately disables saving.

## Tests

```bash
node --test
```

## Storage

`localStorage` prefix `bnb_`, Firestore collection `bubblebrew` in the shared
family `wordvoyage-e5a5c` project. The Firebase config in
`js/firebase-config.js` is a public client config, not a secret — the key is
restricted to the Cloud Firestore API and referrer-checked.

Essence is stored as two monotonic counters (`essenceEarned` / `essenceSpent`)
with the balance derived, because progress merges field-wise by `max()` and a
stored balance would resurrect spent essence on every sync.
